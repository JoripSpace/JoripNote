# JoripNote UI 여백 원칙

## 목적

문서 편집기와 공개 문서, 앱의 관리 화면이 같은 공간 리듬을 사용하도록 한다. 콘텐츠가 카드 테두리에 붙어 보이거나, 인라인 링크 규칙이 카드형 블록을 덮어쓰지 않도록 표면 유형을 분리한다.

## 기본 토큰

| 토큰 | 값 | 용도 |
| --- | ---: | --- |
| `--ui-space-1` | 4px | 텍스트 강조·작은 마커 |
| `--ui-space-2` | 8px | 아이콘과 텍스트, 내부 페이지 링크 |
| `--ui-space-3` | 12px | 모바일 카드·오디오·구조화 블록 |
| `--ui-space-4` | 16px | 데스크톱 카드·코드·오디오 |
| `--ui-space-5` | 20px | 패널·그룹형 앱 표면 |

## 표면별 규칙

- 본문 인라인 링크는 텍스트 흐름의 일부이며 별도 박스 패딩을 갖지 않는다.
- 북마크·파일·미디어 실패 안내는 카드 내부 좌우 16px, 모바일 12px을 사용한다.
- 내부 페이지 링크는 테두리 없는 평면 행으로 표시하되 최소 40px, 모바일 44px의 클릭 영역을 갖는다.
- 이미지·영상·임베드는 시각 콘텐츠를 불필요하게 안쪽으로 줄이지 않는다. 컨테이너의 radius와 실패 안내의 패딩만 적용한다.
- 코드 블록은 헤더와 코드 본문을 분리하고 본문 좌우 16px, 모바일 12px을 사용한다.
- 콜아웃·인용·목차·수식·표·데이터베이스는 내용이 테두리에 붙지 않도록 12~16px 내부 여백을 사용한다.
- 선택 상태는 파란 배경으로만 표현한다. 왼쪽 레일, 임의의 파란 테두리, 중첩된 회색 카드 테두리는 사용하지 않는다.
- 모든 상호작용 컨트롤은 가능한 경우 44px 이상의 터치 영역을 유지한다.

## CSS 적용 원칙

- `.block-content a`처럼 넓은 선택자로 카드형 링크를 스타일링하지 않는다.
- 인라인 링크는 `.block-content:not(.media-block) a`, 카드 링크는 `.media-block .media-preview > a`처럼 표면을 명시한다.
- 편집 문서와 공개 문서에 동일한 콘텐츠 표면 규칙을 적용한다.
- 새 예외 스타일을 기존 CSS 끝에 무작정 추가하지 말고, 이 문서의 표면 분류와 토큰 중 하나로 설명할 수 있어야 한다.
